
# Travel Fare Calculator

## Description
This program calculates the total travel fare based on the distance traveled and the number of passengers. The fare rate is PHP 14 per kilometer per passenger.

## Version 1 - Original code without input validation
- Input: Passenger name, travel distance in kilometers, and number of passengers.
- Process: Calculates the total fare using the distance, fare rate, and number of passengers.
- Output: Displays the passenger's name and total fare in PHP, rounded to two decimal places.
- Validation: Does not include input validation.

## Version 2 - Code with input validation
- Input: Passenger name, travel distance in kilometers, and number of passengers.
- Process: Checks if the name is not empty, the distance is a valid number greater than 0, and the number of passengers is a positive whole number. Uses while loops and try-except to handle invalid inputs.
- Output: Displays the passenger's name and total fare in PHP, rounded to two decimal places.
- Validation: Prevents empty names, invalid distances, and invalid passenger counts.
